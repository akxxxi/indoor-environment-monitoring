## 交付入口

项目根目录双击 `start.cmd`，自动打开 `http://127.0.0.1:5173`。默认采样周期 2000 ms，HTTP 3000 / MQTT 1883。按 Ctrl+C 统一停止；若 Windows 询问 `Terminate batch job (Y/N)?`，输入 Y 结束批处理，此时服务已停止。

启动器为 `scripts/start.mjs`，网页运行入口为 `scripts/web-runtime.mjs`。缺少依赖时自动在对应项目执行 `npm ci`；每次启动重新构建网页。后端 MQTT/SQLite 健康检查、网页 API 代理和真实入库 ACK 均通过后才报告成功。首次依赖安装需要网络，本次验收使用已有本地依赖。

## 联调修复

真实后端停机后，Vite 代理可能对 SSE 重连返回 500/502，使浏览器 EventSource 进入 CLOSED，原先只依赖原生重试无法在后端恢复后恢复页面。

前端现对 CLOSED 状态以 1 秒起步、最多 15 秒的退避重新建立订阅；CONNECTING 状态仍用原生重试。重连后同步 REST 快照、阈值和曲线，清理旧订阅与定时器。已添加专门回归用例，并通过真实后端停机/恢复测试；始终只有一条活动 SSE。

后端与节点入口新增启动器 IPC 正常停止支持。节点通过 IPC 通知真实 stored/duplicate ACK，供启动器判断链路就绪。退出按节点→网页→后端执行，节点保留待确认队列；启动器失联时子进程也会关闭。
