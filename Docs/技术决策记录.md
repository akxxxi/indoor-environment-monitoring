## 本次采用的工程默认值

以下属于可调整的实施细节，并非用户对每个字段的单独指定。

| 编号 | 默认值 | 目的 |
| --- | --- | --- |
| E01 | 三个独立 npm 项目与 JavaScript ESM | 各自维护 package.json、package-lock.json 和 node_modules，支持 Agent 并行工作 |
| E02 | 本机 Node.js 24.15.0 与 npm 11.12.1 | 使用已检查环境，避免本阶段额外安装运行时 |
| E03 | MQTT 3.1.1，上传 QoS 1 | 兼容预定设备接入并配合应用确认 |
| E04 | 上传体为 UTF-8 JSON，负载不超过 1024 字节 | 便于调试并控制未来设备缓冲区 |
| E05 | `dust_ug_m3`，网页标注粉尘浓度估算值 | 对应 GP2Y1010 粉尘输出口径 |
| E06 | 唯一键为设备、启动批次、序号 | 覆盖断网补传、重启和重复投递 |
| E07 | 事务提交后应用层确认 | 防止只收到 MQTT 确认就过早清除队列 |
| E08 | SQLite 优先使用 `node:sqlite` | 当前运行时已验证可用，存储模块封装驱动 |
| E09 | ECharts 与 CSS 过渡 | 满足趋势和动画，控制首版依赖数量 |
| E10 | MQTT 1883、HTTP 3000、Vite 5173 | 统一本地配置，启动时检查占用 |
| E11 | 只监听 127.0.0.1 | 满足本机演示；局域网访问另行配置 |
| E12 | 默认中文界面，内部存 UTC 时间 | 显示按 Asia/Shanghai，避免补传时间混淆 |
| E13 | 暂不自动清理历史数据 | 保留演示与验收证据，后续实测后决定保留期 |
