## 必须完成

1. 使用 Vite、React、JavaScript JSX 与 ECharts。保留现有项目目录及 package.json 包名，直接在目录内补齐骨架，不另建嵌套项目。默认网页 5173，开发代理把 `/api` 转给 `http://127.0.0.1:3000`，SSE 同样走代理。
2. 提供实时看板和历史查询两个页签，不必为两个视图额外引入路由框架。默认一个教室、一个设备，无登录页、设备管理页或多教室选择器。
3. 实时页显示五张指标卡、最近更新时间、设备状态、数据过期状态、实时连接状态和虚拟数据标记。粉尘名称为“粉尘浓度估算值”，单位 μg/m³，不写 PM2.5。缺测显示占位文字，不能用零补齐。
4. 展示最近约 10 分钟的趋势，可选择单一指标，不在同一坐标轴混合不同单位。通过 REST 获取初始数据，通过一条 EventSource 接收更新；只保留有限窗口，按记录 ID 去重，历史补传不能让最新值回退。
5. 历史页提供最近 1 小时、6 小时、24 小时和自定义起止时间，最长单次 7 天；指标切换、查询、加载、空结果和错误状态完整。调用 series 接口，不向浏览器下载全部原始历史记录。
6. 用简洁弹窗或侧面板编辑工程演示阈值，通过 GET/PUT thresholds 保存并展示保存结果。隐藏复杂配置技巧即可，不扩展成通用规则编辑器。根据后端 alarms 展示当前超限与恢复反馈，不在前端另算一套正式报警状态。
7. 界面采用浅暖灰背景、白色卡片、清晰留白与青绿色重点色。数字过渡、图表更新、页签和弹窗有适度动画，响应减少动态效果的系统设置；390 px 左右手机宽度不溢出。
8. SSE 重连后重新获取快照和曲线，页面离开时关闭连接、定时器和图表实例。无新数据时能随时间进入过期状态。React 开发模式不能留下重复连接或重复定时器。

## 保持简单

- 原生 fetch、EventSource、React hooks 与 CSS 足够。不要引入 Redux、通用请求框架、大型 UI 组件库或多套动画库。
- 动画服务于数字、曲线和状态反馈，不增加 3D 场景、大屏轮播、粒子背景或持续占用 CPU 的装饰。
- 不做账号、云服务、PWA、原生手机应用、导出报表、国际化、暗色模式或独立报警记录中心。
- 不要求品牌 Logo 或生成图片，不以设计资源缺失为由停工。
- 正常运行必须使用后端数据，不能偷偷用随机数制造“已接通”效果。后端未启动时显示明确连接失败或无数据状态；布局预览确需本地 fixture 时只用于开发验证、明确标记且默认关闭，不新增一套 mock 服务。
- 可以先独立完成页面，不修改后端迎合自己的字段定义。

## 修改范围

只修改 `Projects/web`，包括自己的 package.json、package-lock.json、.npmrc、node_modules、源代码与 README。三个项目依赖独立，你可以与其他 Agent 同时安装、编码和测试，无需等待。不要在 Projects 下创建统一依赖文件，不要改其他项目、原始 Word 或共用协议。不提交 Git、不发布网站。不要创建新 Agent 或新聊天。
